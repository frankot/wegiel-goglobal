# O firmie

Sekcja zawiera dane firmy, dla której liczony jest ślad węglowy.

## Do czego służą te dane

- **NIP** — przy imporcie faktury system porównuje go z NIP-em nabywcy. Jeśli się różnią, pokaże ostrzeżenie, że faktura może nie dotyczyć Twojej firmy.
- **Nazwa i adres** — trafiają do nagłówka raportów PDF.
- **Nazwa skrócona** — wyświetlana w panelu bocznym (jeśli jej nie podasz, widoczna jest pełna nazwa).

## Edycja danych

**Tylko Manager**

1. Przejdź do **O firmie** (albo kliknij nazwę firmy w panelu bocznym).
2. Uzupełnij lub popraw pola:
   - **Dane identyfikacyjne**: Pełna nazwa (obowiązkowa), Nazwa skrócona, NIP, REGON, KRS,
   - **Adres**: Ulica i numer, Kod pocztowy, Miejscowość, Kraj.
3. Kliknij **Zapisz**. Pojawi się komunikat „Zapisano dane firmy".

Pracownik widzi dane firmy tylko do odczytu. Jeśli nie zostały jeszcze uzupełnione, poproś Managera o ich dodanie.
